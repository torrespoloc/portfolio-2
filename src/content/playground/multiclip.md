Ok so picture this: you're deep in a coding session, you've copied three different things from GitHub, and then - oops - you copied one more and your last repo URL is gone. **Poof.**

I got tired of that dance about **27 million times**, so I built **MultiClip**. It's a menu bar app that lets you copy several things at once. Basically a clipboard history that doesn't make you panic when you lose something.

Built it as an **MVP over a weekend** (honestly, those are my favorite kinds of projects). It sits quietly in the menu bar, complements SideNook really nicely, and was genuinely fun to build with SwiftUI. There's something satisfying about making native Mac tools.

## Highlights

- Menu bar utility for always-available clipboard access
- Clipboard history with easy retrieval of older clips
- Seamlessly complements SideNook workflow
- Built with SwiftUI for native macOS feel
