# Jiro Health Presentation Deck

Two output formats: **web viewer** (`/presentation`) and **.pptx** (`build-deck.mjs`).

## File Map

| File | Purpose | Safe to edit? |
|------|---------|---------------|

| `docs/2026-05-25-presentation-overhaul.md` | Original design brief | No — archive |
| `docs/2026-05-25-presentation-overhaul-plan.md` | Implementation plan | No — archive |

| `../src/app/presentation/layout.tsx` | Route layout/metadata | **Yes** — presentation only |

## Running the Build

```bash
cd presentation
node build-deck.mjs
```

Output: `assets/jiro-health-presentation.pptx`

## Running the Web Viewer

```bash
cd ..
npm run dev
# → http://localhost:3000/presentation
```

## Workflow

1. Edit slides in `page.tsx` (web) and/or `build-deck.mjs` (.pptx)
2. Test web: `npm run dev` → `/presentation`
3. Build pptx: `cd presentation && node build-deck.mjs`
4. Keep copy and assets in sync between both formats
